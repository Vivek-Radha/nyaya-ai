# NyayaAI

Justice Made Simple with Artificial Intelligence.

## Overview
NyayaAI is a startup-grade SaaS platform designed to help ordinary citizens understand legal issues using AI. 

**IMPORTANT**: NyayaAI provides legal guidance for educational purposes only and should not be treated as legal advice.

## Tech Stack
- **Frontend**: React, TypeScript, Vite, TailwindCSS
- **Backend**: FastAPI, Python
- **Database**: PostgreSQL (Supabase)
- **AI**: Groq API, pgvector, OCR (Tesseract)

## Getting Started
1. Install dependencies for frontend and backend.
2. Setup environment variables (see `.env.example`).
3. Run `docker-compose up` to start the local environment.
